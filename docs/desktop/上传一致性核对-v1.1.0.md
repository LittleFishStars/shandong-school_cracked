# 上传数据一致性核对：v1.1.0 ↔ 当前版本（2026-10-23）

## 基准

- 最后一个发布版：**v1.1.0**（`585f04e`，tag `v1.1.0`，产物 `shandong-school_cracked-1.1.0-*`）
- 当前版本：`main`（本次核对时 `2b4c1e7` 之后的工作树）
- 两版代码分别用 `git archive v1.1.0` 与当前工作树，**同一套 mock 流程**各跑一次完整跑步

## 方法

对同一输入、同一随机种子，录下客户端 `transport.post` 发往服务端的全部上传报文：

| 项 | 值 |
|---|---|
| 模式 | `mock`（本地仿真服务端，不碰真实网络） |
| 目标距离 | 1200 米 |
| 随机种子 | `20261023` |
| 其他参数 | 默认配置（步频 172–182、步幅 0.85、摇杆速度 2.5 m/s） |
| 采集接口 | `uploadRunRecord` / `uploadStepsRecord` / `uploadPaceRecord` / `uploadStrideRecord` / `uploadPassPoint` / `finishSunRun_v2` |

两版各产出 **11 条**上传报文，接口序列完全一致：

```
upload_record ×1 → upload_step ×1 → upload_pace ×1 → upload_stride ×6 → upload_passpoint ×1 → finish_sun_run ×1
```

## 结果

逐字段递归比较（浮点按 1e-9 容差）：

- **业务字段差异：0**
  - 轨迹 `pois`：182 点，`lat/lng/index/state/accuracy/offFenceDisM/satellites` 逐点一致
  - 步频 `stepList`、配速 `paceList`、步幅 `strideList`（6 段）逐段一致
  - 打卡点 `targetPoints`：数量、`lat/lng/passStatus/code` 一致
  - 结算：`distance/duration/totalStep/status/stepInterval/paceInterval/alignType/pauseCount/pauseTimes/sportType` 一致
  - 公共头：`modelName/appVersion/buildVersion/channel/appCode/systemVersion/platform/deviceId` 一致
- **差异全部落在必然变化的字段**（共 393 条，均为“当前时刻/记录号”类）：

| 字段 | 条数 | 说明 |
|---|---|---|
| `timestamp` | 11 | 每次请求的服务端时间戳 |
| `runRecordCode` | 11 | 服务端生成的记录号 |
| `runImgRecord` | 1 | 依赖 timestamp 的防篡改码 |
| `pois[].collectTime` / `createTime` | 182 × 2 | 采集时钟 |
| `targetPoints[].clockTime` | 3 × 2 | 打卡时钟 |

## 代码层核对

v1.1.0 → 当前，上传链路文件的实际改动：

| 文件 | 差异 | 是否影响上传报文 |
|---|---|---|
| `net.py` / `store.py` | 0 行 | 否 |
| `engine.py` | `load_rule` 多一个 `allow_abstract_fallback=False`；GPX creator 改名 | 否（只影响规则拉取方式与导出文件） |

| `client.py` | 规则解析（`schoolDemandRule`）、历史账号名 | 否（不构造上传 payload） |

## 复现

```bash
# 1) 导出基准
git archive v1.1.0 | tar -x -C /tmp/baseline-v1.1.0

# 2) 两版各跑一次并把 transport.post 的上传 payload 落 JSON（同一参数/种子）
python scripts/verify-upload/capture_upload.py sdlab                   /tmp/baseline-v1.1.0 /tmp/upload-baseline.json /tmp/run-baseline
python scripts/verify-upload/capture_upload.py shandong_school_cracked projects/desktop    /tmp/upload-current.json  /tmp/run-current

# 3) 比较（忽略 timestamp/runRecordCode/runImgRecord/各时钟字段）
python scripts/verify-upload/compare_upload.py /tmp/upload-baseline.json /tmp/upload-current.json
```

## 结论

当前版本在所有上传接口上与 v1.1.0 的报文**结构一致、业务字段逐值一致**；差异仅限每次请求必然不同的时间戳、记录号、防篡改码与时钟字段。本次界面/规则展示相关改动**没有触碰上传数据**。
